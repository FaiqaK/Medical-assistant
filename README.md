# 🩺 MediGuide AI — Medical Assistant Chatbot

MediGuide AI is an AI-powered medical information chatbot developed using **Python, Streamlit, LangChain, and the OpenAI API**.

The project provides users with a simple conversational interface where they can ask health and medical-related questions. The assistant is configured with a fixed medical system role so that it focuses specifically on healthcare-related topics rather than behaving as a general-purpose chatbot.

The application also maintains conversation history during the current session, allowing users to ask follow-up questions while preserving the context of previous messages.

> ⚠️ MediGuide AI is an educational project. It provides general health information and is not intended to replace professional medical advice, diagnosis, treatment, or emergency services.

---
# 📖 Project Overview

Many users search online when they have questions about symptoms, medical terminology, medications, nutrition, laboratory tests, or general health concerns.

Traditional search engines may return information from many different sources, requiring users to read several pages before finding useful information.

MediGuide AI explores how a **Large Language Model (LLM)** can be integrated into a simple web application to provide conversational health information.

Instead of searching through multiple pages, a user can type a question such as:

```text
What are common causes of headaches?
```

The application sends the question, conversation history, and medical system instructions to an OpenAI model through LangChain.

The generated response is then displayed in a Streamlit chat interface.
# ✨ Key Features

## 🩺 Medical-Focused Assistant

The chatbot uses a fixed system role that tells the AI to focus on medical and healthcare-related questions.

Example topics include:

- Symptoms
- Diseases
- General health concerns
- Nutrition
- Healthy habits
- Medical terminology
- Medical tests
- General medication information
- Warning signs
- Healthcare information
## 🚫 Non-Medical Question Restriction

The system prompt instructs the model not to behave like a general-purpose chatbot.

For example:

```text
User:
Can you explain Python programming?

Assistant:
I am a medical assistant and can only help with health-related questions.
```

This allows the application to remain focused on its intended domain.
